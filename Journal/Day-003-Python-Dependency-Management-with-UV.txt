Task
------------------------------------------------------------

The xFusionCorp Industries ML team uses UV and lockfiles to
maintain consistent Python dependencies across different
machines.

A requirements.in file had been created by a teammate, but it
did not follow the company's standards.

My objective was to:

• Correct the requirements.in file.
• Keep only the required top-level packages.
• Generate a pinned requirements.txt lockfile using UV.

------------------------------------------------------------
Initial Situation
------------------------------------------------------------

When I opened the project directory, the existing
requirements.in file looked like this:

# Fraud detection project dependencies
sklearn
mlflow>=100.0
numpy

Immediately, I noticed that something looked incorrect,
especially the version specified for mlflow.

------------------------------------------------------------
Failures and Challenges
------------------------------------------------------------

1. Wrong Package Name

The file contained:

sklearn

At first, I assumed this was correct because in Python we use:

import sklearn

However, I learned that the package installed from PyPI is
actually called:

scikit-learn

The import name and installation package name are different.

Solution:
Changed

sklearn

to

scikit-learn

------------------------------------------------------------

2. Invalid Version Constraint

The requirements file contained:

mlflow>=100.0

Initially, I didn't understand why this was wrong.

After reading the task carefully, I realized that this version
doesn't exist on PyPI, so UV cannot resolve the dependency.

Solution:

I removed the impossible version requirement and simply wrote:

mlflow

This allowed UV to automatically resolve the latest compatible
version.

------------------------------------------------------------

3. Missing Required Package

The task specifically required these four packages:

• scikit-learn
• mlflow
• pandas
• numpy

But the original file didn't include pandas.

Solution:

Added

pandas

to the requirements.in file.

------------------------------------------------------------
Corrected requirements.in
------------------------------------------------------------

# Fraud detection project dependencies
scikit-learn
mlflow
pandas
numpy

------------------------------------------------------------
Commands Used
------------------------------------------------------------

Navigate to project

cd /root/code/fraud-detection

View current file

cat requirements.in

Edit file

nano requirements.in

Generate lockfile

uv pip compile requirements.in -o requirements.txt

Verify generated file

cat requirements.txt

------------------------------------------------------------
Result
------------------------------------------------------------

UV successfully generated a requirements.txt file.

The lockfile contained:

• Exact versions using ==
• All four top-level packages
• Every required transitive dependency

This ensures every developer installs the exact same package
versions, making the project reproducible across different
machines.

✔ Difference between package installation names and Python

scikit-learn
