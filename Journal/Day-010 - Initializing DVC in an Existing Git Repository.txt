# 🧠 What is DVC?

**Data Version Control (DVC)** is an open-source tool designed for Machine Learning projects.

Git is excellent for tracking source code, but it is not designed to efficiently manage large datasets or trained model files.

DVC extends Git by allowing developers to version:

* Datasets
* Machine learning models
* Pipelines
* Experiments

while keeping only lightweight metadata inside the Git repository.

This makes collaboration easier and keeps repositories small.

---

# 📁 Understanding the Generated Files

## `.dvc/`

This hidden directory stores DVC configuration files used to manage data versioning.

### `.dvc/config`

Stores project-specific DVC settings.

### `.dvc/.gitignore`

Prevents Git from tracking DVC cache files that should remain outside version control.

---

## `.dvcignore`

Works similarly to `.gitignore`, but is used by DVC to ignore files and directories during data tracking.
