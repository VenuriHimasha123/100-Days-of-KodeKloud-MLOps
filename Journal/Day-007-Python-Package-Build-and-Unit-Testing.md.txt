# Problem 1 - Incorrect pyproject.toml Configuration

### Initial Configuration

The project contained:

```toml
[project]
name = "fraud-detection"
version = "0.0.1"
requires-python = ">=3.8"
dependencies = []
```

### Issues

Several required configurations were missing:

- No `[build-system]`
- Incorrect project name
- Wrong version
- Wrong Python version requirement
- Missing dependencies
- Missing pytest pythonpath configuration

### Solution

Updated the configuration to:

```toml
[build-system]
requires = ["setuptools>=61.0", "wheel"]
build-backend = "setuptools.build_meta"

[project]
name = "fraud_detection"
version = "0.1.0"
description = "Fraud detection model for xFusionCorp Industries"
requires-python = ">=3.10"
dependencies = [
    "scikit-learn",
    "pandas",
    "numpy"
]

[tool.setuptools.packages.find]
where = ["src"]

[tool.pytest.ini_options]
pythonpath = ["src"]
```

This satisfied all packaging requirements.

# Problem 2 - Missing Unit Tests

Initially there were no proper unit tests validating the model.

### Solution

Created:

```
tests/test_predict.py
```

Added two unit tests.

```python
from fraud_detection import predict


def test_fraud_transaction():
    data = [[150]]
    assert predict(data) == [1]


def test_legitimate_transaction():
    data = [[100]]
    assert predict(data) == [0]
```

These tests verify:

- Fraud transaction (amount >100)
- Legitimate transaction (amount <=100)

# Problem 3 - Swap File Created During Editing

While creating the test file using `vi`, the editor was accidentally left without exiting properly.

This created:

```
tests/.test_predict.py.swp
```

### Why It Happened

The `vi` editor was interrupted before saving or exiting correctly.

### Fix

Removed the swap file:

```bash
rm -f tests/.test_predict.py.swp
```

Then recreated the test file correctly.
